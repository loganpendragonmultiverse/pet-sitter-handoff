# Security

Pet sitter handoff has no server or runtime dependencies. Inputs remain in the browser. JSON imports are size bounded, versioned and schema checked before replacement; user text is rendered as text. Storage is not encrypted, and exported files can contain private information. Only use a browser profile and device you trust.

Report a vulnerability through this repository’s private GitHub security reporting page. Avoid attaching personal backups to public issues. No security fix or response deadline is promised.
